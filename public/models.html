🤖 ローカル ONNX モデル一覧

日本語プロンプトの英語直訳に加え、Stable Diffusion向けにアイテム単体・構図タグの最適化や推奨ネガティブ生成（AIアシスト）を行うローカルLLM（Transformers.js / ONNX）を選択・常駐化します。

📦 未登録のダウンロード済みキャッシュ (ディスク容量解放)

設定一覧には登録されていませんが、ディスク上にダウンロード済みファイル（キャッシュ）が残っているモデルです。
不要な場合はキャッシュを削除してディスク容量を解放するか、一覧に再登録できます。

🌐 外部 LLM サーバー / ルーター接続設定 (OpenAI 互換 API)

llama.cpp server、Ollama、LM Studio、LiteLLM / OpenWebUI ルーター、vLLM などの OpenAI 互換エンドポイントに接続します。
ルーターモードや複数モデルを配信しているサーバーの場合は、「🔄 モデル一覧を取得」ボタンでサーバーから利用可能なモデル一覧を取得して選択できます。

💡 主なエンドポイント例:
・llama.cpp server: http://localhost:8080/v1
・Ollama: http://localhost:11434/v1
・LM Studio: http://localhost:1234/v1
・LiteLLM / 各種ルーター: http://localhost:4000/v1
※ llama.cpp 単体などモデル一覧取得に対応していないサーバーの場合は手動で default 等を入力してください。

⚡ OpenAI (ChatGPT API) 接続設定

OpenAI の公式 API を使用して、極めて高精度なプロンプト英訳・構図タグ最適化・ネガティブ補完を行います。
APIキーを入力後に「🔄 モデル一覧を取得」を押すと、アカウントで利用可能な全モデル一覧を取得して選択できます。

※ APIキーは conf/localLlm.json に安全に保存され、サーバー間通信でのみ使用されます。
